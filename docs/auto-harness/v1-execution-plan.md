# Auto Harness v1：包虫病超声分型执行方案

更新：2026-10-04。按当前要求直接覆盖既有方案，不增加版本。基础分型 Agent、独立专家训练及本文分型 Auto Harness 已实现；旧概率版 auto-harness 入口已替换，旧实验日志保留。新流程已通过全仓 160 项离线测试、Ruff 和真实数据 dry-run，尚未运行真实付费优化实验。运行步骤见 [Auto Harness 指南](README.md)。基础运行见 [Agent 指南](../agent/typing-agent.md)，专家训练见 [专家指南](../expert/typing-classifier-v1-runbook.md)。

## 1. 七类任务与输出

只允许 `NO_HE, CE1, CE2, CE3, CE4, CE5, AE`。NO_HE 表示非包虫病，AE 属于包虫病。CE3 不细分 CE3a/CE3b，AE 不细分泡型亚型。**禁止输出 CL**；知识材料中的 CL 定义只保留在原文转录，不作为任务标签。

```json
{"status":"ok","predicted_type":"CE2","confidence":0.75,"findings":["可见囊内子囊样结构"]}
```

confidence 为标签正确的未校准自评，必须是 [0,1] 有限数值，不是患病概率。不可判读返回 `status: abstain`，类别与 confidence 为 null；非法标签（含 CL）及无效响应记为 error。初判、复核均遵守相同协议；复核返回自身 confidence。

## 3. 固定初判与单层复核动作

采用“BASELINE 初判 → 按初判类别和 confidence 选择一个动作 → 接受或一次独立复核”。固定视觉模型、图片预处理、参考七图及顺序、知识来源、模型采样参数；真值、文件名、来源不输入识别模型。图内诊断文字按统一审核规则处理。

每张图先调用一次 BASELINE，仅输入原图与初判提示，不加参考图、完整医学知识或检查表，得到 `c0, q0`。路由只使用这一次的预测类别与 confidence，不使用真值，也不按复核结果再次路由。初判返回 error／abstain 时直接结束，仍计入评价分母；初判有效但分类错误时照常路由，推理阶段并不知道其是否分类正确。

| 动作 | 输入与执行含义 |
| --- | --- |
| `ACCEPT` | 直接返回初判，不增加调用 |
| `REVIEW_CHECKLIST` | 原图＋中性复核指令＋简短鉴别检查表 |
| `REVIEW_REFERENCE` | 原图＋中性复核指令＋固定七张参考图 |
| `REVIEW_KNOWLEDGE` | 原图＋中性复核指令＋完整分型知识 |
| `REVIEW_REFERENCE_CHECKLIST` | 原图＋中性复核指令＋七张参考图＋同一检查表 |

所有复核均包含相同的只读七类输出协议，不看初判类别、confidence 或理由，独立输出自己的结论与 confidence。复核结果直接替换初判，包括错误或弃权；每图在线调用为 **1–2 次**。参考图＋检查表在同一次请求中输入，不构成连续两次复核。

检查表提供简短的观察与鉴别步骤，完整知识提供分型说明；本轮固定比较上述 **5 个动作**，不自动扩展到所有输入组合。既有基础 Agent 的其他模式保留供独立实验。复核输入背景见 [复核方案](../agent/review-input-proposal.md)。

## 4. 内层：本地精确优化类别阈值

对每个 **BASELINE 预测类别**，允许一条不分段的动作规则；或者选择 `t∈{0.1,0.2,…,0.9}`，在 `q0<t` 和 `q0≥t` 两侧各选一个动作。不预设低 confidence 必须复核、高 confidence 必须接受。两侧动作相同则规范化为不分段；不分段规则阈值为 null，避免把没有意义的阈值称为最优值。

每类规则数为 `5＋9×5×4＝185`，七类共 **1295 次局部规则评价**。另外枚举每类五种不分段动作，得到 `P_type`，共 35 次；合计 **1330 次本地评价／提示词版本，静态优化器 LLM 调用为 0**。

每个冻结提示词版本的流程：

1. 在完整 **190 张搜索图**上采集 **3 轮**。每轮采集一次 BASELINE；初判有效时，分别采集四种独立复核，形成五个动作的结果表，其中 ACCEPT 直接复用初判。每图每轮最多一次初判＋四次复核，即五次模型调用。这是搜索阶段用于比较动作的完整采集，线上只执行被选中的一个动作。初判无效时跳过全部复核，但保留失败结果。
2. 一个 `(图片, 轮次, 输入配置)` 只采集一次，所有规则复用该观测；重复编号不保证远程模型确定性。复核输入完全相同的请求可共享同轮缓存，线上调用数仍按实际执行路径计算。
3. 冻结缓存，按 `c0` 分组。每类选择三轮正确数之和最多的规则；并列先选**完整执行路径的模型调用数最少**者，再选规范化配置字典序最小者。空预测类别固定 `ACCEPT`。
4. 合并七类规则得到 `P_joint`，复算总体分数；另计算 `P_type` 作为搜索侧复杂度诊断。固定类别顺序和排序字段 JSON 作为配置比较顺序。

正确数和调用数可按预测类别相加，且没有跨类别调用预算约束，因此此算法得到**固定提示词、固定缓存、固定阈值网格下的全局最优**。不等于连续阈值空间最优，也不保证未来图片最优。费用／token 单独报告，调用数只是并列时的选择依据。

## 5. 外层：LLM 累积经验优化提示词

认同增加 LLM 优化器，但它是**开发阶段的提示词提案器**。本地程序负责评分、选策略与判定是否接受；LLM 不自行宣告进步，也不在线改提示。

### 允许修改的内容

- 初判提示：BASELINE 的可编辑任务说明，包括观察顺序、证据表达及 confidence 自评说明；保持不附参考、完整知识或检查表的输入边界。
- 复核提示：四种复核共用的中性指令，以及检查表的组织、措辞与观察顺序；参考比较指令只在提供参考时生效。各动作的参考／知识／检查表开关固定，不由 LLM 改变。
- 七类标签、JSON 协议、弃权规则、独立复核约束、医学知识事实、参考图片、模型参数和数据划分为只读。医学表述只能在现有知识材料支持范围内改写，保存来源；不能加入搜索图片 ID、来源捷径、个别样本答案或按图记忆规则。

实现采用受约束文本块优化：LLM 选择和重排 `src/auto_harness/prompts.py` 中已审核的观察指令及现有提示块，检查表医学条目必须全部保留。初判与复核分别有独立可编辑顺序；医学知识正文和七类协议只读。暂不自动接受自由文本医学改写，未知文本块直接拒绝。这是当前可自动校验的提示词优化边界。

初始提示包 `V0` 使用现有七类基础提示、中性复核提示、检查表及完整分型知识。先分离只读输出契约与可编辑内容，保存实际拼接后的全部提示及哈希。动态修改后 confidence 的分布和类别分组可能变化，**必须重新求阈值，不能继承旧版本的“最优阈值”**。

### 迭代流程与经验记录

1. 完成 `V0` 的三轮搜索采集及内层求解，作为初始 incumbent（当前最佳完整方案）。先验证静态流程可复算，再启用外层。
2. 每轮向 LLM 提供：当前最佳提示包与规则、截至当前的全部提案摘要、修改差异、准确率和成本变化、按预测类别／真实类别的混淆、纠错与引错案例、失败假设和未解决问题。案例只来自搜索集，去掉身份及来源信息；真值仅供离线优化器分析，不进入识别模型请求。
3. 要求输出结构化提案：`parent_version`、`evidence_ids`、`hypothesis`、`target_component`、`prompt_patch`、`expected_effect`。每轮只改“初判”或“复核”一类组件，便于解释结果。
4. 本地校验父版本、历史证据引用、输出协议与只读约束；医学语义冲突、样本答案嵌入等无法可靠校验的提案拒绝并记录。无效或重复提案同样消耗一轮，不无限重试生成。
5. 对合法新提示包，在全部 190 张搜索图上补采受影响的三轮结果，重新求 `P_joint`。缓存按完整请求输入和轮次匹配；修改初判后重新采集初判并重建分组、失效分支及路径计数。未改变且独立的复核请求可以复用，但不能挪用另一提示的结果。
6. 按搜索正确总数、实际调用总数、配置规范序比较新方案与 incumbent。只有严格胜出才更新 incumbent；失败提案也写入经验。下一轮基于 incumbent 和完整历史继续。
7. **最多四轮提案**，即含 `V0` 最多五个提示包；连续两轮未改进（含无效提案）提前停止。搜索结束后冻结候选，再打开选型结果。

持久化 `prompt_versions/`、追加写入的 `optimizer_history.jsonl`、`experience_summary.json` 和 `incumbent.json`。每条经验链接原始指标、缓存及差异；每轮保存实际发送的上下文、模型响应和父版本。摘要由程序根据实验记录生成，不让 LLM 凭记忆维护成绩。

**能保证的是：每轮收到可追溯的累计经验，候选经过可复算评价，当前最佳不会因提案而退步。不能保证 LLM 必然理解经验或产生更好提示；若没有改善，就保留静态方案。** 多轮反复利用搜索集会产生适配风险，外层最优只指已试过的提示包，不是全部提示空间全局最优。

## 6. 冻结选型、测试与真实使用

最多三个候选，以完整提示包＋七类规则为单位冻结：

1. `S0`：`V0` 的 BASELINE，不复核。
2. `P_static`：`V0` 下的 `P_joint`。
3. `P_dynamic`：外层最终 incumbent 的 `P_joint`；若与前两者相同则去重。

`P_type` 只作搜索侧诊断，不额外扩大选型候选。初判 CE1 固定复核、随机复核等旧对照不再列为本轮默认测试项。

在 **76 张选型图**上，每个冻结候选执行完整在线路径三轮；只执行实际路由，不展开所有反事实动作。不同提示包分别取得自己的 BASELINE 初判，相同输入共享同轮观测。以三轮正确总数排序，并列先选模型调用数少者，再按规范序。选型集不反馈给提示优化器，不重调阈值或追加候选。

冻结胜者后，在 **119 张测试图**上三轮评价三个已冻结候选，用于比较无优化、仅静态、静态＋动态优化的贡献；测试结果不改变胜者。真值仅用于离线评分，推理时只执行对应提示包和规则：

`BASELINE → (预测类别, confidence) → ACCEPT 或四种复核之一 → 最终类别或弃权`

线上没有优化器调用或经验更新；固定知识 prompt 和参考图按所选动作使用。未来再训练／再优化须重新开启开发流程。

主指标为三轮准确率均值，每轮以完整计划样本数作分母；错误、弃权、非法标签及未完成样本均算不正确。辅助报告七类召回率、宏召回率、混淆矩阵、来源分层、有效输出覆盖率、纠错／引错、实际调用数、token／费用、延迟及初判 confidence 固定十分位分箱。差异按已知关联组做配对 bootstrap，重复运行不是独立患者；单次或搜索侧改善不视为泛化证据。

## 7. 调用预算、记录与实现边界

以下为不复用跨版本缓存、无失败跳过、三个候选均不同的保守逻辑调用上限：

| 阶段 | 计算 | 视觉模型调用上限 |
| --- | --- | ---: |
| 单提示包搜索 | 190 图×3 轮×5 次 | 2850 |
| 全部搜索 | 最多 5 个提示包×2850 | 14250 |
| 选型 | 76 图×3 轮×(S0 的 1 次＋两个策略各 2 次) | 1140 |
| 测试 | 119 图×3 轮×(1＋2＋2) | 1785 |
| 合计 | 搜索＋选型＋测试 | **17175** |

外层另最多 **4 次 LLM 提案调用**；若两种模型请求均允许最多一次传输／协议重试，实际请求上限为视觉 **34350**、优化器 **8**。无效内容不额外补提案；重试仍计费用。共享输入、只修改复核、提前停止及候选去重会降低实际开销。

单层动作将每图在线调用上限降为两次；完整搜索仍需采集四种复核用于比较，加上最多五个提示包，费用主要来自开发采集。实施顺序为：先做 `V0` 静态采集与成本测量，再按预先冻结的费用／token 上限启用最多四轮外层优化。不足以完成一个版本的三轮全搜索时不启动该版本；部分结果保留但不能与完整候选同分母选优。**本文件更新不代表已经发起付费实验。**

记录标签／划分／图像哈希、模型参数、完整请求与提示来源、参考哈希、动作表、185 条每类规则分数、提示变更历史、候选冻结及选型依据。旧日志保留，只有请求身份、输入及重复编号完全匹配的缓存才可复用；不同提示的结果不能混计同一版本。

分型 Auto Harness 已实现每类单层动作路由（包括 BASELINE 初判后独立添加参考或完整知识）、共享缓存回放、四轮累积经验优化、候选冻结、选型测试及部署预测。基础 Agent 的统一阈值接口和专家训练流程保持独立。旧概率配置／缓存明确拒绝复用；新实验使用新工作目录，代码及入口沿用原路径。预算停止后可通过 `budget` 命令提高额度并恢复，保留调整记录。token 为服务方已报告用量停止值，不构成金额硬预算，实际费用需查看服务方账单。
