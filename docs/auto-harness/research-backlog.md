# Auto Harness 备选研究方案：尚未执行

> 2026-10-04：当前任务已切换为分型，执行依据见 [分型方案](v1-execution-plan.md)。下列早期设想保留原讨论背景，涉及概率区间的内容需重新设计。

记录日期：2026-10-03。本文保存讨论中提出、但尚未作为 auto harness 实验实施的方向，避免与[第一版进度与冻结协议](v1-progress.md)混淆。部分基础模块已有历史探索，不代表下列自动优化方案已实现或有效。

当前优先推进第一版的受限复核策略搜索；以下方案分阶段进入，不同时扩展全部变量。

## 1. 自适应参考图选择与追加

- **问题：** 为不同待测图选择不同参考病例，能否优于固定示例？是否值得在初判后追加参考图？
- **设想：** 固定四图／随机四图／检索四图对照，再允许策略决定是否增加到八图。控制类别比例、图数及顺序，记录逐例选图。
- **已有基础：** 固定参考增强有开发证据；TinyUSFM 特征原型已运行。当前八图全发送时没有检索选择空间。
- **进入条件：** 参考池与评估病例隔离、排除同患者与近重复；最小实验可从八图中选两阳两阴，进一步研究需扩大多来源参考池。
- **验证重点：** 概率质量、来源多样性、检索稳定性与成本；判断选到的是疾病相关形态还是设备／文字风格。
- **边界：** TinyUSFM 相似度不是患病概率，查询真值不能参与选图。编码器优劣必须对照验证。
- **优先级：** 第一版之后优先考虑。

## 2. 按需调用医学知识卡片

- **问题：** 过去长医学提示词没有稳定增益，是否因为内容过多或介入时机不合适？
- **设想：** 图像独立观察 → 提出待澄清问题 → 检索有限知识卡 → 复核。优化卡片选择、数量和调用时机。
- **对照：** 不加知识、固定短知识、按需知识；保持模型和预算可比。
- **进入条件：** 建立人工核验且来源可追溯的卡片库；医学事实固定，优化器不能为提高分数擅改医学标准。
- **验证重点：** 是否真正改善概率质量，还是强化初判错误；检查检索是否只返回支持既有结论的内容。
- **状态：** 只有设计；现有医学提示词试验不等于已经完成按需知识实验。

## 3. 在复核门控中引入更多可观测信号

- **问题：** 初判概率不足以判断复核收益时，图像质量、结构化观察或证据冲突能否提供额外信息？
- **设想：** 将经验证的质量标记、结构化影像观察、工具失败状态等纳入控制器；考察对高置信度错误的识别能力。
- **对照：** 仅概率门控、逐项增加信号、等预算随机复核。
- **进入条件：** 明确字段语义、标注或核验方法和推理成本；所有信号必须能在未知标签的新病例上获取。
- **风险：** 模型自报“依据充分”“图像清晰”不是可靠性真值；自由文本中可能包含来源捷径。新增字段需要单独验证，不能直接提升为硬医学规则。
- **状态：** 第一版暂不纳入，先保留概率和响应状态输入。

## 4. 训练小型动作选择模型

- **问题：** 能否用小模型预测哪种后续动作最有价值，而不是用 LLM 生成条件程序？
- **设想：** 输入初判及可观测信号，预测各动作的预期收益或选择动作。这个模型负责分流，不必直接从图像诊断包虫病。
- **训练数据：** 开发病例的初判、各动作结果、真值与成本。某动作未执行时，其反事实收益未知，不能直接编造监督标签。
- **对照：** 人工规则、普通搜索、LLM 生成策略；从简单且受正则化的模型起步。
- **进入条件：** 有足够独立病例和动作覆盖，能隔离训练／验证／测试；现有选择性复核日志不足以直接支撑完整动作监督。
- **推理阶段：** 运行冻结的小模型选择动作，再调用视觉大模型；不在线训练。
- **状态：** 未训练；不是当前选定的第一版优化方式。

## 5. 真实推理时由 LLM 动态规划流程

- **问题：** 每例都让控制 LLM 判断下一步，是否比冻结程序更灵活且有实际收益？
- **设想：** 控制 LLM 根据当前观察选择接受、复核、检索或调用工具，受固定预算约束。
- **与第一版区别：** 第一版仅开发时用 LLM 修改策略；本路线在测试和真实使用时也增加控制 LLM 调用。
- **对照：** 冻结规则／小模型控制器，报告额外 token、时延、失败和随机性；不能仅比较准确率。
- **进入条件：** 证明固定控制器存在明确不足，并具备可靠工具及可审计执行记录。
- **优先级：** 较低，当前不需要增加这层复杂性。

## 6. 接入疾病分类专家或 ROI 工具

- **问题：** 系统能否自动决定何时调用专家，以及如何处理专家与视觉大模型的冲突？
- **设想：** 在独立验证工具之后，把专家调用加入动作空间；先分开验证专家本身与接入后的增益。
- **已有基础：** TinyUSFM 特征提取已有原型，HE_DCNN 权重兼容性有技术探针；尚无已验证的 HE 疾病专家进入主流程。
- **进入条件：** 权重、类别语义、输入预处理、训练来源重叠和许可核验；ROI 分割需匹配标注和独立质量评价。
- **对照：** 无工具、工具独立预测、原图加工具、成本相近的普通复核。
- **边界：** 通用超声特征不是疾病概率；CT 分割模型不能直接充当超声分类专家；不能把分割置信度或面积比例当作患病概率。
- **状态：** 自动工具调度未执行；详见[专家模型研究记录](../../experiments/expert_lab/research-report.md)。

## 7. 跨模型与跨来源迁移

- **问题：** 在 GLM 或某些开发来源上找到的策略，能否直接迁移到另一识别模型或新来源？
- **设想：** 比较冻结策略直接迁移、少量开发反馈后重新优化、分别从头优化；分开记录迁移收益与适配成本。
- **进入条件：** 第一版有稳定协议；第二模型接口可靠；患者／来源关系明确，有两类标签可用的新来源数据。
- **验证重点：** 分来源概率质量、覆盖率、复核收益，以及策略是否依赖模型自报概率的特定尺度。
- **边界：** 目标来源一旦用于适配即成为开发数据，需另外保留最终测试。来源与类别完全绑定时，不能将来源识别能力解释为疾病泛化能力。
- **状态：** 已有 GLM／DeepSeek 对照不是自动策略迁移实验。

## 8. 后续扩展与暂不合并的变量

- **多步停止与弃权：** 将来可探索何时继续补充信息、何时停止或转人工；需明确覆盖率与风险／成本曲线，防止只输出容易病例。第一版仅一次可选复核，错误／弃权语义固定。
- **概率融合与校准：** 可比较初判／复核融合及独立校准，但需要独立开发／校准数据。第一版固定最终输出规则，不同时搜索融合权重或阈值。
- **联合优化提示词、参考图和工具：** 在单模块贡献明确后再扩大搜索空间，逐项消融。当前全面开放修改会加剧小样本过拟合并难以归因。
- **持续更新：** 不在真实使用中自动根据未核验结果更新策略。若未来研究持续改进，应等待可靠标签，以新一轮开发、验证、冻结版本的流程进行。

## 9. 推进顺序与记录约定

建议顺序：第一版复核控制 → 参考图选择或门控信号扩展 → 按需知识 → 数据成熟后的动作模型与工具调度。跨来源测试贯穿评价，跨模型迁移在协议稳定后开展。

每项从备选转为执行前，新建或更新对应执行方案，写明研究假设、输入与动作、数据划分、预算、对照、主指标、停止条件及版本。只有完成运行并保存结果后才标记“已执行”；没有正向效果的结果同样保留。
