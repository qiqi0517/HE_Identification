标签依据为既有 CE 分期清单及医院提供的类别目录，对照 [PPT 分型说明](../knowledge/echinococcosis-ultrasound-typing.md) 做名称映射。没有通过模型或图像外观推断真值，也没有从二分类阳性推断 CE 分期。AE 不归入 CE1–CE5；CL 不能替代正常或非包虫病标签。

主标签类别分布：CE1=77、CE2=20、CE3=24、CE4=48、CE5=32、AE=22。“主任务标签可用”仅表示来源标签明确，不表示已经通过患者、图像泄漏或临床复核。

## 整理方式与文件

- 保留全部输入图像字节，旧 UUID 不变，新 UUIDv5 沿用旧命名空间，以 SHA-256 生成；文件名不编码类别。包括医院 `1.JPG` 在内的大小写扩展名均已纳入。
- 按文件字节去重并记录多重来源；本次没有精确字节重复，也没有相同 RGB 解码像素组。未将外观相似的图自动删除，近重复另待审核。
- 所有 409 张图均成功解码，复制后 SHA-256 与输入一致。
- `labels/labels_typing.txt`：223 张主标签，格式 `images/UUID.jpg CE1`，标签为字符串；路径相对于新数据集根目录。
- `labels/manifest.jsonl`：全部 409 张的来源、原目录标签、明确／疑似状态、哈希、尺寸、原二分类字段及像素组 ID。
- `labels/typing_review.jsonl`：47 张疑似 CE2、139 张缺少分型标签的图片，独立于主标签。
- `labels/legacy_snapshot/`：旧标签、uuid_mapping、病例关联与既有排除记录的完整副本。
- `summary.json`、`checksums.json`：数量统计、整理边界和产物哈希。

医院样例来自用户说明的合作医院，具体机构名称和逐病例审核记录未提供。保留原文件路径仅用于本地溯源，不作为模型输入。没有从 DICOM 风格 UID 推测患者身份；原文件名、图内身份／诊断文字仍可能存在，尚未进行脱敏和遮挡。后续在向模型发送图片及建立正式划分前审核这些内容。

主任务暂不使用旧非包虫病图，也不删除它们。医院疑似 CE2 在取得明确标注后可建立下一数据版本，不能直接改写冻结版本的真值。原来单独保存的 37 张未标注图和 8 条 review 排除记录没有重新引入。

## 复现

在含 Pillow 的 `he` 环境、仓库根目录运行。当前输出已经生成，复现时换一个不存在的输出目录：

```bash
python scripts/data/merge_hospital_typing.py \
  --legacy data/unified \
  --hospital data/samples \
  --output data/unified_typing_v1_rebuild
```

脚本拒绝覆盖已有输出，未知目录或文件会报错，使用临时输出完成校验后才发布整个数据目录。旧数据、医院原始目录和旧实验缓存均仅读取。

尚未生成 reference/search/selection/test 新清单；新分型协议见 [v1-execution-plan.md](../auto-harness/v1-execution-plan.md)。
