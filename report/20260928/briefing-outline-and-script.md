## 第 4 页：判断阈值与复核范围的选择

**时间：约 45 秒**

### 页面内容

标题：判断阈值需分别选择，扩大复核范围未必更好

两表均使用最新十组实验的 **202 张共同有效图像**。

**① 判断阈值：固定预测概率，比较默认值与事后最优值**

| 模型／配置 | t=0.5 准确率 | 最优 t 示例 | 最优准确率 |
| --- | ---: | ---: | ---: |
| GLM 基础 | 71.78% | **0.18** | **90.59%** |
| GLM 参考 8 图 | 80.69% | 0.25 | 89.60% |
| GLM 8 图＋复核* | 79.70% | 0.25 | 90.59% |
| DeepSeek 基础 | 59.41% | 0.18 | 65.84% |
| DeepSeek 参考 8 图 | 68.81% | **0.60** | **69.80%** |

*复核区间保持 (0.1,0.3)，仅离线改变最终判断阈值。最优 t 为并列最优值中的一个示例。*

**② 复核范围：均用 8 图，固定判断阈值 t=0.30**

| 复核区间 | GLM 准确率 | DeepSeek 准确率 |
| --- | ---: | ---: |
| 不复核 | 87.13% | **66.34%** |
| **(0.10, 0.30)** | **89.60%** | 63.37% |
| (0.05, 0.30) | 87.13% | 60.89% |
| (0, 0.30) | 88.12% | 63.86% |

**核心结论：** GLM 基础版调阈值后提高 **18.81 个百分点**；复核以 GLM 的 (0.1,0.3) 为当前候选，DeepSeek 暂未显示复核增益。

**页脚：** 阈值为开发数据事后最优，尚未独立验证；复核各组独立初判，差异包含生成波动。

**呈现建议：** 左侧约六成宽度放判断阈值表，右侧放复核表。底部只保留核心结论和口径说明。两表分别标明“各组选最优 t”和“固定 t=0.30”，避免把分数混用。口头只讲 GLM 基础、DeepSeek 参考和较窄复核区间三个例子；其余行供老师快速查看。

### 演讲稿

阈值选择也很重要。在同一批图片上，GLM 基础版用默认零点五时，准确率约百分之七十二，改为零点一八后约百分之九十一。但 DeepSeek 参考版的最优阈值是零点六，不能直接套用 GLM 的值。右表固定判断阈值零点三，GLM 在零点一到零点三之间复核表现较好，扩大范围没有继续改善，DeepSeek 则暂未受益。这些是开发数据上的候选，还需要独立验证。

### 备注与口径（不放在页面正文）

- GLM 基础版最优 t∈(0.15,0.20]，其中不同子区间的 FN／FP 组成不同，但正确总数相同；表中示例选 0.18。
- GLM 参考版及参考＋复核 (0.1,0.3) 的最优 t∈(0.20,0.25]。
- DeepSeek 基础版最优 t∈(0.15,0.25]，参考版最优 t∈(0.55,0.60]。括号左开右闭来自规则 `p_he >= t` 判阳性。
- 复核组的 90.59% 是保留实际复核区间 (0.1,0.3)，再用 t=0.25 对最终概率离线重评分的结果。**不等价于直接把在线命令的 `--threshold` 改成 0.25 重跑**，因为该参数还会改变复核上界。
- 改判断阈值不会改变已有概率，也不会改变其 Log loss 或 AUC。只能据此说明在这批开发标签上的分类取舍得到改善。

- 下界按 0.10、0.05、0 依次降低时，GLM 全部 211 张任务中的额外复核调用数为 **47／100／108**，DeepSeek 为 **36／54／65**。这是完整运行的成本，不能写成仅针对 202 张共同样本的调用数。
- GLM 在三个复核配置下，202 张上的 FN／FP 分别为 **9／12、9／17、9／15**。扩大范围的两组没有减少最终漏判，却有更多误报。这是跨运行观察，不能单独归因于下界。
- 各模型每个配置仅一次运行，202 张共同有效口径还排除了错误／弃权图。下一步应冻结同一份初判，在复核缓存覆盖足够时比较候选下界，并另报完整任务的覆盖率和调用成本。
- 左表单独优化每组最终判断阈值；右表固定 t=0.30 比较复核配置，两表回答的问题不同，不应混用分数。

- 左表相对 t=0.5 的准确率提升依次为 **18.81／8.91／10.89／6.44／0.99 个百分点**。这是判定方式的改变，不是重新调用模型后获得的新预测。
- 右表按“不复核／下界 0.10／0.05／0”的顺序，GLM 的 Log loss 为 **0.4288／0.4126／0.4487／0.4451**，DeepSeek 为 **0.5875／0.6159／0.6445／0.6448**。完整概率指标保留在备注，正文聚焦准确率对比。
