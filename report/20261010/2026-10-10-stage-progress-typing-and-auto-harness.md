## 3. 搭建七类分型 Agent 并完成真实实验

### 3.1 从概率输出改为分型输出

基础 Agent 已统一输出 `status / predicted_type / confidence / findings`。其中 confidence 表示模型对本次标签正确性的未校准自评，不表示患病概率；不可判断时允许弃权，非法标签、格式错误及弃权均保留在准确率分母中。

已实现四种初判模式：BASELINE、参考图、医学知识、参考图＋医学知识。参考模式读取新划分中的固定七张示例；医学知识依据项目提供的《包虫分型.pptx》整理为 Markdown 与提示词，并保存知识来源及哈希。

### 3.2 复核机制和提示词改进

复核由初判 confidence 触发，最多追加一次调用。复核不读取初判类别、confidence 或理由，独立判断；最终采用复核输出，包括复核失败或弃权。

本阶段保留旧中性复核作为对照，新增中性复核提示和简短鉴别检查表，并将复核的参考图、完整医学知识、检查表输入分别设为可控制开关。这样可以考察不同输入是否纠正初判，以及是否把原本正确的结果改错。

### 3.3 八组基础 Agent 实验结果

八组使用相同 **190 张搜索图**、GLM `glm-5.3-flash`，每组运行一次。已逐图复算指标并核验样本与配置一致性。

| 组别 | 配置 | 最终正确数 | 准确率 | 复核相对本组初判的净正确变化 |
| --- | --- | ---: | ---: | ---: |
| E1 | BASELINE，不复核 | 129/190 | 67.89% | — |
| E2 | 七参考图，不复核 | 132/190 | **69.47%** | — |
| E3 | 医学知识，不复核 | 132/190 | **69.47%** | — |
| E4 | 参考图＋知识，不复核 | 126/190 | 66.32% | — |
| E6 | 组合初判＋旧中性复核，阈值 0.6 | 132/190 | 69.47% | +1 |
| E7 | 组合初判＋新中性复核，阈值 0.6 | 130/190 | 68.42% | −2 |
| E8 | 组合初判＋检查表与参考图复核，阈值 0.6 | 129/190 | 67.89% | 0 |
| E9 | 组合初判＋检查表复核、不加参考图，阈值 0.6 | 116/190 | 61.05% | −9 |

E5 没有完整结果，本轮汇总不包含该组。

**主要发现：**

1. 参考图与医学知识单独输入并列最高，但相对 BASELINE 都仅多正确 3 张，尚不足以认定稳定提升。知识模式已报告 token 为参考模式的约 **35.7%**，具有进一步比较输入成本的价值；token 比例不是实际费用比例。
2. 同时加入参考图和知识没有显示更好结果，说明输入信息增加未必带来收益。
3. 复核必须同时统计纠错与引错。本轮复核约增加 42% 的逻辑调用，但总体净收益有限；无参考检查表组净减少 9 张正确判断。
4. CE4 是共同难点，主要混淆为 AE、CE3；模型对不同类别的复核收益存在差异，为按类别选择动作提供了研究动机。

这些是搜索集单次观测。复核组各自重新生成初判，不能把不同组的最终差值全部归因于提示词，也不能用它们直接拼接严格配对的 Auto Harness 动作表。

## 4. 训练分类专家小模型

### 4.1 已完成的三条路线

为探索较低推理成本、可本地运行的分类专家，已实现并训练以下七分类模型：

| 路线 | 模型与训练方式 | 研究目的 |
| --- | --- | --- |
| S1 | 冻结 TinyUSFM，训练线性分类头 | 检验超声预训练特征的分型能力 |
| S2 | 冻结 ImageNet 预训练 ResNet18，训练线性分类头 | 提供通用视觉特征基线 |
| S3 | TinyUSFM 分类头预热，再微调最后两层及归一化层 | 检验有限微调能否适应当前任务 |

训练流程已包含特征缓存、训练集标准化、类别加权、早停、最佳 checkpoint 保存、指标与混淆矩阵、冻结参数验证、选型及单图预测。三条初始路线完成后，进一步开展九组调整实验。

### 4.2 九组调整实验

以下均为 **seed=42、相同 76 张验证图**的结果，不能与基础 Agent 的 190 张搜索集成绩作直接排名。

| 配置 | 调整内容 | 验证正确数 | 准确率 | 宏平均召回 |
| --- | --- | ---: | ---: | ---: |
| S1_default | TinyUSFM 原始特征 | 35/76 | 46.05% | 28.30% |
| S1_standard | 训练特征逐维标准化 | 40/76 | **52.63%** | **48.53%** |
| S1_long | 最多 200 轮，按验证 loss 早停 | 39/76 | 51.32% | 42.49% |
| S2_default | ResNet18 默认分类头训练 | 41/76 | **53.95%** | 45.96% |
| S2_wd1e3 | weight decay=0.001 | 41/76 | **53.95%** | 46.09% |
| S2_wd1e2 | weight decay=0.01 | 41/76 | **53.95%** | 46.09% |
| S2_weighted | 类别频数平方根倒数加权 | 40/76 | 52.63% | 45.58% |
| S3_default | 默认有限微调 | 34/76 | 44.74% | 26.79% |
| S3_head1e3 | 微调阶段分类头学习率提高到 0.001 | 34/76 | 44.74% | 26.99% |

**主要发现：** S2 当前准确率最高；S1 标准化提升了少数类别覆盖，宏平均召回最高，值得继续。增加 S2 正则化没有提高正确数，类别加权也未体现总体收益。S3 提高分类头学习率后仍未解决学习不足，暂不适合作为主要候选。

最佳 checkpoint 的补充训练集评估显示：S2 默认训练准确率约 92.89%、验证 53.95%，泛化差距明显；S1 标准化训练约 81.73%、验证 52.63%；S3 两组训练准确率仅约 39%，更接近学习不足。

**提出但尚未完成的后续工作：** 补齐 seed=43、44 后再正式选型；在比较前隔离特征缓存提取与训练采样的随机状态，避免缓存命中差异影响批次顺序；对 S3 尝试更充分的分类头预热及按 loss 早停；检查 CE3／CE4 训练与验证错例。专家模型尚未作为正式复核动作接入 Auto Harness，其辅助价值仍需独立实验。

## 5. Auto Harness：从人工调参走向可追溯自动优化

### 5.1 方案演进与取舍

最初探索的是固定视觉模型下的概率分段策略优化，随后随任务变化改为分型准确率优化。对于冻结动作缓存，可以本地穷举找到有限策略空间最优，不必让 LLM 搜索阈值。

曾提出两层动作：先选 BASELINE／KNOWLEDGE／REFERENCE，再选复核方式。但这会使单图最多调用三次；独立复核又不使用中间判断，部分中间调用没有贡献。因此最终简化为**一次 BASELINE 初判＋选择一个接受／复核动作**，将单图在线调用上限降至两次。

### 5.2 当前五动作空间

| 动作 | 输入与处理 |
| --- | --- |
| 接受结果 | 直接复用 BASELINE 初判 |
| 检查表复核 | 原图＋中性指令＋鉴别检查表 |
| 参考图复核 | 原图＋中性指令＋固定七参考图 |
| 医学知识复核 | 原图＋中性指令＋完整分型知识 |
| 参考图＋检查表复核 | 在一次请求中同时输入原图、七参考和检查表 |

所有路由都依据**初判预测类别与 confidence**，不使用真实标签。复核独立判断并直接作为最终输出。初判 error／abstain 无有效路由信息时结束，仍纳入评分分母。

### 5.3 内层：静态精确优化器

搜索集每图采集三轮，每轮共享一次初判，并采集四种复核结果。在缓存固定后，每个预测类别可以选择：

- 全部采用同一个动作；或
- 在 0.1–0.9 的九个候选阈值中选一个，阈值两侧分别采用不同动作。

每类共 **185 条规则**，七类分段优化为 1295 次本地评价；另加不分段对照 35 次，共 **1330 次本地评价／提示词版本**。按正确数最多、调用数最少、规范顺序选择，优化器不调用 LLM。由于各类可独立求解，能得到固定缓存、固定阈值网格内的全局最优，但不保证未来数据最优。

### 5.4 外层：积累经验的 LLM 提示词优化器

外层负责修改初判或复核提示，每次修改后补采受影响结果，再运行静态优化，避免沿用旧提示下的阈值。

已实现以下机制：

- 提案输入包含当前最佳方案、全部历史摘要、失败尝试、混淆和搜索错例；保存父版本、证据 ID、修改假设及提示差异。
- 每轮只修改初判或复核一类组件；当前实现是选择、重排已审核文本块，不自动接收自由医学文本改写。知识事实、标签协议、参考图和输入开关固定。
- 由程序计算实际成绩，判断是否更新当前最佳；失败提案同样保留，经验摘要从实验记录生成。
- 最多四轮提案，连续两轮未改进停止；相同请求可复用缓存，避免重复采集。

该机制保证优化器获得可追溯的累计经验，不能保证 LLM 必然理解经验或产生增益。LLM 优化器仅在开发阶段使用，真实识别只执行冻结提示与策略。

### 5.5 工程实现与验证

旧概率版 auto-harness 已由分型代码覆盖，历史运行记录保留。现已实现初始化、动作采集、本地搜索、提示词优化、候选冻结、选型、测试、导出及新图预测，并提供请求日志、哈希绑定、断点恢复和预算调整。

开发验证已通过 **160 项全仓离线测试**、Ruff 检查、合成数据完整流程，以及真实数据初始化和 dry-run。初始提示包的搜索采集上限为 **190×3×5＝2850 次逻辑调用**；完整五提示包加选型、测试的保守上限为 17175 次视觉模型调用，实际数量受缓存复用、提前停止和候选去重影响。

## 7. 可用于口头汇报的简短总结

上次汇报主要研究包虫病的有无识别。这一阶段，我们引入合作医院超声样例，将数据整理为 392 张七类分型图片，并搭建了输出类别和置信度的分型 Agent。八组实验显示，参考图与医学知识模式在当前搜索集上均达到 69.47%，但增加输入和复核并不一定提高准确率。我们同时训练了三条专家小模型路线，完成九组调整实验，发现通用视觉特征和超声特征标准化值得进一步研究。针对复核收益不稳定的问题，我们实现了 Auto Harness：本地优化器按类别和置信度选择动作，LLM 结合累计实验经验修改提示词，单张图最多调用两次模型。Auto Harness 已获得初步结果，具体性能和成本对比将在实验结束后补充。

本段最后一句为预写口径；正式使用前按第 5.6 节核实并补齐结果。
